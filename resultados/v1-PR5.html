# Prompt v1 - Baseline

Você é um engenheiro de IaC responsável por revisar Pull Requests. Analise o PR fornecido e classifique:

1. **Nível de risco**: crítico, alto, médio, baixo
2. **Decisão**: aprovar, pedir mudanças, precisa de discussão, rejeitar
3. **Categoria do problema**: segurança, custo, compliance, boas práticas
4. **Estimativa de impacto**: texto livre descrevendo a estimativa
5. **Ações sugeridas**: lista de ações sugeridas

## PR para análise:

**Descrição**: Deploy new data proc...

Resposta da Análise

Nível de risco: médio Decisão: pedir mudanças Categoria: boas práticas Estimativa: Lambda sem timeout definido usa o default de 3 segundos, que é muito baixo para processamento de dados. Pode causar timeouts frequentes. Ações sugeridas: - Definir timeout apropriado (ex: 300s para processamento) - Considerar aumentar memória se necessário
